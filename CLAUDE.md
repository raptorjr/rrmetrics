# Claude Code instructions

This repository uses one shared instruction set for all AI coding agents.

**Read [AGENTS.md](AGENTS.md) first**, then read [docs/AI-DEVELOPMENT-GUIDE.md](docs/AI-DEVELOPMENT-GUIDE.md) before planning or changing code.

Those files are the source of truth for:
- Branch discipline and the GitHub workflow.
- Architecture and product direction.
- Code quality, tests, CI, data safety, and documentation requirements.
- The project owner's collaboration preferences.
- Unraid deployment procedure and the rule that deployment requires explicit authorization.

Do not maintain a separate, conflicting set of technical assumptions here. Always inspect the current `development` branch and working tree; old conversation summaries are not proof of current repository state.
